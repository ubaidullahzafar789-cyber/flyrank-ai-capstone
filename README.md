# FlyRank AI Capstone

This repository is the starting point for a FlyRank AI internship capstone project.

## Project Status

The project includes a small dependency-free settings form.

## Technology

The project uses plain HTML, CSS, and JavaScript. Node.js is used to run the test suite.

## Getting Started

Open `index.html` in a browser to use the settings form. Run `npm test` to execute the validation tests. No dependency installation is required.

## Contribution Guidelines

- Inspect existing documentation and code before making changes.
- Keep changes focused, simple, and maintainable.
- Use Conventional Commits for commit messages.
- Do not add dependencies unless they are necessary and their purpose is documented.
